# Inscritos Play

Este repositório publica o site estático do Inscritos Play com o HTML fornecido.

## Publicação

O site é publicado automaticamente via GitHub Pages usando GitHub Actions.

## Configuração do Supabase

No arquivo `index.html`, substitua:

- `COLE_AQUI_A_URL_DO_SEU_PROJETO`
- `COLE_AQUI_A_CHAVE_PUBLICA_ANON`

pelos valores do seu projeto Supabase.

## Acesso

Depois do deploy, o site fica em:

https://theovictorcontato-hue.github.io/inscritos-play/
